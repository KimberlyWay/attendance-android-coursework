# Посещаемость группы

Учебное Android-приложение на Java для учёта посещаемости одной группы по календарным дням. Данные сохраняются локально в SQLite. Интернет, регистрация и сервер для работы не требуются.

## Возможности

- Добавление студентов и редактирование имени.
- Журнал по выбранной дате: «Не отмечен», «Присутствовал», «Отсутствовал», «Опоздал».
- Одна актуальная отметка на студента и дату. Повторный выбор заменяет отметку.
- Итоги за все сохранённые даты по каждому студенту.
- Экспорт сохранённых отметок в CSV через системное окно сохранения.
- Удаление студента с подтверждением и каскадным удалением его истории.

Учёт ведётся по дням, без отдельных дисциплин и пар. CSV является отчётом, импорт и восстановление базы не реализованы. База удаляется при удалении приложения. Для демонстрации используйте вымышленные сведения.

## Android Studio

1. Распакуйте исходный ZIP или клонируйте репозиторий.
2. В Android Studio выберите File → Open и корень с `settings.gradle`.
3. Установите SDK Platform 35 и выберите Gradle JDK 17.
4. Используйте включённый Gradle Wrapper 8.9. Дождитесь синхронизации.
5. Выберите телефон с USB-отладкой либо эмулятор и запустите конфигурацию `app`.

Минимальная версия Android: 6.0 (API 23). compileSdk и targetSdk: 35. Android Gradle Plugin: 8.7.3.

Сборка из терминала Android Studio:

```bash
./gradlew assembleDebug
```

В Windows:

```powershell
.\gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка

В `app/src/androidTest` находятся два инструментальных сценария. Первый проверяет валидацию имени, уникальность отметки, статистику, переименование, удаление связанных данных, CSV и повторное открытие базы. Второй запускает три экрана и сохраняет их снимки. Проверка выполняется на Android 15 (API 35). На других версиях и при увеличенных размерах шрифта требуется дополнительная проверка.

```bash
./gradlew connectedDebugAndroidTest
```

Средства автоматической сборки находятся в `.github`. Они не нужны для открытия проекта и разработки в Android Studio. В ZIP-копии без Git эту папку можно удалить.

## Структура

- `MainActivity.java` — экраны, ввод, календарь и системное сохранение файла.
- `DatabaseHelper.java` — схема SQLite, запросы и CSV.
- `AttendanceTest.java` — инструментальные проверки.
- `AndroidManifest.xml` — регистрация главного экрана, без сетевых разрешений.

Распространяемый APK является отладочной сборкой для учебной демонстрации. Для постоянного распространения обновлений нужно настроить собственный постоянный ключ подписи.
